# ФТСО — сайт Федерации тенниса Смоленской области (ftso67.ru)

Репозиторий сайта. Два каталога, и они соседи не случайно:

```
site/     приложение: каркас на Node, публичная главная, живой раздел «Рейтинг»
rating/   рейтинговый движок — подключается как модуль, не переписывается
```

`site/` обращается к движку относительными путями (`../rating/rating.mjs`,
`../../../rating/export.mjs`). Раскладка перенесена один в один из репозитория,
где каркас собирался, поэтому импорты не менялись. Поднимать `site/` в корень
нельзя — сломает все эти пути.

Подробности по каркасу, ролям, безопасности и эксплуатации — в
[`site/README.md`](site/README.md). Про сам движок — в
[`rating/README.md`](rating/README.md).

## Запуск

Все команды выполняются **из каталога `site/`** — `package.json` лежит там, а не
в корне.

```bash
cd site
npm install
cp .env.example .env      # заполнить SESSION_SECRET и SUPER_ADMIN_PASSWORD
npm run migrate           # схема; ОТДЕЛЬНОЙ командой ДО старта сервера
npm run seed              # выдуманные данные + два снимка рейтинга
npm start                 # http://127.0.0.1:3000
```

Главная — `/`, рейтинг — `/rating`.

## Приёмка

```bash
cd site
npm run accept
```

Поднимает изолированную базу во временном каталоге и ничего не трогает в рабочей.

## Требования

Node.js 20 или новее. База — SQLite (`better-sqlite3`), внешних сервисов нет.

## Секреты

Реальные значения живут в `site/.env` и в git не попадают: `.env` и `*.sqlite`
закрыты в `site/.gitignore`. В репозитории — только образец `site/.env.example`.
Пароль супер-админа берётся из окружения и **меняется при первом входе**
(«Мой аккаунт» → «Смена пароля»).
