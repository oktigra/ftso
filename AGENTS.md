# AGENTS.md — для любого исполнителя (человека или ИИ)

Этот репозиторий не привязан к конкретному ИИ. Правила, устройство и порядок работы
одинаковы для всех:

1. **Главный файл с правилами — [`CLAUDE.md`](CLAUDE.md).** Название историческое: там
   правила проекта для любого исполнителя, не только для Claude. Прочитать первым.
2. **Что сделано и что осталось** — [`docs/claude/state.md`](docs/claude/state.md) и
   соседние файлы в `docs/claude/`.
3. **Как внести правку и выложить на сайт по шагам** — [`docs/HOWTO.md`](docs/HOWTO.md).

Коротко о главном:
- `main` — это боевой сайт ftso67.ru. Сервер сам забирает `main` раз в 2 минуты.
- В `main` напрямую не пушить. Только ветка → PR → слияние после явного «да» владельца.
- Перед слиянием — точка отката: ветка/метка `rollback/<ГГГГ-ММ-ДД>-before-<что>` на текущем `main`.
- Репозиторий **публичный**: никаких паролей, токенов, IP, адресов серверов и персональных данных.
