## ПРОВЕРЕНО — уже в ядре, заново НЕ чинить (замер по коду 121022e)

- security-заголовки БОГАТЫЕ: CSP вручную (default-src self; script-src self+nonce; frame-ancestors none; object-src none; base-uri self; form-action self; img-src self+data:), X-Frame-Options DENY, Referrer-Policy strict-origin-when-cross-origin, nosniff, HSTS за HTTPS в проде.

- СЕССИЯ: rolling + maxAge 12ч = истечение по бездействию (idle timeout) уже есть.

- action_log ПОЛНЫЙ (вход/выход, CRUD всех сущностей, recompute, пароли) — дыр аудита нет.

- rate-limit на /login (login-attempts по «логин+IP») и на запись (writeLimiter). 403 для неверной роли — есть.

- SESSION_SECRET в .env вне git; ротация — ТОЛЬКО при компрометации.

- трансграничной передачи ПДн НЕТ by design: шрифты самохост, почта Яндекс (РФ), сервер MSK (РФ). Куки только сессионные, аналитики нет.

- СРОК ХРАНЕНИЯ профилей — НЕ автоснос: профиль живёт, пока игрок в системе; удаление по заявлению (право на забвение).
