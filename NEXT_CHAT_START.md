# ВХОД В ЧАТ ПО ФТСО — нулевой шаг всегда здесь

Память проекта ФТСО живёт В ЭТОМ репозитории, не в домике WGR (`claude-house` про
ФТСО не знает — проверено 03.09.2026 грепом по 97 сессиям). Чат по памяти не
работает: состояние снимается заново каждую сессию.

## Входной пакет (Олег прикладывает в первом сообщении)

1. ТЗ или письмо задачи.
2. `gh_token_write.txt` — токен с записью в `oktigra/ftso` (проба: POST `git/refs`
   с нулевым sha → `422` = запись есть).
3. Всё остальное чат берёт сам: клон, `BACKLOG.md`, `COMPLIANCE.md`, этот файл.

## Нулевой шаг — три команды, без них ни строки вывода о состоянии

```
git clone https://x-access-token:$GH_TOKEN@github.com/oktigra/ftso.git && cd ftso
cd site && npm ci --silent && cp .env.example .env   # SESSION_SECRET и пароли — любые строки
node OPEN.mjs            # клон, legal.mjs, бой снаружи; --accept — приёмка (~2,5 мин)
```

Дальше — блок «ВХОД СЛЕДУЮЩЕЙ СЕССИИ» ниже (последние два), затем `BACKLOG.md`.

## Правила этого репозитория, которые не выводятся из общих

- Доставка: ветка + PR, патчи запрещены. Мерж в `main` → автовыкат на бой за ≤2 мин
  (`deploy/deploy-watch.sh` → `/root/deploy-A.sh`: `npm install`, `npm run migrate`,
  `pm2 restart`, проверка 200 по `/`, авто-откат). Новые страницы `/` не проверяет —
  после выката замерять их снаружи самому.
- Репозиторий ПУБЛИЧНЫЙ: в снимках и коде — ни токенов, ни паролей, ни почт, ни ПДн.
- Модель публикации — РТТ (ТЗ ред. 6, 02.09.2026): результаты по факту участия,
  согласие и 18 лет на витрину не влияют. Старые тексты про «Скрыто по заявлению»
  и «снятие в 18» в `COMPLIANCE.md` — история.
- Выход из хода: приёмка сошлась числами либо назван красный, который чат сам не
  закроет. Вопросы «продолжать?» и «скажи, если мимо» — нельзя.
- Закрытие сессии — ТРАФАРЕТ РИТУАЛА, один на все проекты, лежит в
  `oktigra/orchestrator-sandbox` (`tools/ritual.mjs`, описание проекта —
  `tools/ritual/ftso.json`; форма пачки — в шапке скрипта). Пачка кладётся в
  `ritual/` этого клона, затем:
  ```
  git clone https://x-access-token:$GH_TOKEN@github.com/oktigra/orchestrator-sandbox.git /tmp/sandbox
  GH_TOKEN=$GH_TOKEN node /tmp/sandbox/tools/ritual.mjs ftso <N> "<сообщение>" --clone "$PWD"
  ```
  Кнопки владельца нет: скрипт сам открывает и сливает PR; замок — в PR ритуала не
  может быть ничего, кроме `sessions/`, `ritual/` и этого файла.
