# Инструменты для живого сайта (только с VPS исполнителя)

Пароли здесь не хранятся. Логин и пароль админки — в приватном репозитории `oktigra/ftso-private`
(`docs/access.md`); на VPS они лежат в `~/.secrets/ftso-admin.env` (переменные `FTSO_ADMIN_USER`, `FTSO_ADMIN_PASS`).
Скачанные страницы, cookie-файл и результаты — в `~/ftso-live` (вне репозитория: там персональные данные).

## adm.sh — сессия админки из консоли
```
. tools/live/adm.sh; alogin            # вход, ответ «login 302»
aget /admin/players > ~/ftso-live/players.html
apost /admin/… k=v …                   # POST с _csrf со страницы
```
Через админку вносились данные 17–18.10.2026 (импорт протоколов, разряды, пересчёт рейтинга).
Любая запись через админку — изменение боевого сайта: только по поручению Алекса и после выгрузки/бэкапа.

## check-rating.py — независимая сверка рейтинга
Пересчитывает очки по методике 2026 (категория турнира → размер сетки A32 B24 C16 D8, очки за победу по группе,
проценты мест, пары пополам вверх, 10 лучших) и сравнивает с шестью списками на `/rating`.
Нужные файлы в папке: `players.html` (`/admin/players`), `t<ID>.html` (`/tournaments/<ID>`) и `r<ID>.html`
(`/admin/tournaments/<ID>/results`) для турниров из словаря `TOUR` в начале скрипта, `rating-<adult|u17|u13>-<single|pair>.html`
(шесть списков со страницы `/rating`). Новые турниры — дописать в `TOUR` (группа и дата).
18.10.2026: 0 расхождений по турнирам #4, #6, #7, #8.
