## Уроки
- Запуск копии для скриншотов: `DB_FILE=<врем>/x.sqlite UPLOAD_DIR=<врем>/up PORT=3123 INTAKE_ENABLED=1`,
  `npm run migrate && npm run seed`, `node server/index.mjs &`; Playwright с `executablePath` из `CHROMIUM_PATH`.
  Headless-Chromium показывает даты в американском формате независимо от локали — это не ошибка сайта.
- `pkill -f "node server/index.mjs"` в той же команде Bash убивает саму команду (код 144) — запускать отдельно.
- Новые колонки базы — только `addColumnIfMissing` в `db/migrate.mjs`; CHECK-ограничения схемы не менять ALTER-ом.
- Аудит 09.10.2026 (закрыт #276): все админ-формы теряли ввод при ошибке → общее восстановление через
  sessionStorage в `public/js/app.js`; даты в админке — поля даты; на публичных страницах — ДД.ММ.ГГГГ.
  Метод аудита: разбор всех полей форм в шаблонах, путей ошибок в обработчиках POST, обход карты сайта, Playwright на копии.
