# ТЗ: логотип ФТСО на сайте ftso67.ru

Согласованный знак. Все файлы лежат в `static/img/logo/`. Ниже — что куда ставить, геометрия, цвета, эффект, анимация и приёмка.

## Файлы

| Файл | Что это | Где применяется |
|---|---|---|
| `ftso-seal.svg` | Основной знак: плашка-корт в пропорции 23.77×10.97, кольцо, мяч с «ФТСО», круговая надпись | от 160 px по ширине: OG-картинка, футер, страница «О Федерации», документы, афиши, аватары |
| `ftso-mark.svg` | Компактный знак: корт с мячом, без надписей | 52–100 px: шапка сайта, кабинет, мобильное меню, водяной знак |
| `ftso-favicon.svg` | Квадратная иконка 1:1 | favicon, иконка приложения, ярлык |
| `ftso-mark-animated.svg` | Компактный знак с летящим вращающимся мячом, стиль внутри файла | инлайн в шапке и в декоративных вставках |

Растровые копии сгенерировать из SVG: `og-ftso.png` 1200×630 (знак по центру, фон #16232b, поля не меньше высоты мяча), `favicon-32.png`, `favicon-180.png` (apple-touch, фон #0d5236).

## Геометрия

Единая система координат обоих SVG — viewBox `0 0 480 222` (2.162:1, пропорция теннисного корта). Ничего не перерисовывать и не перестраивать: масштабировать только целиком.

- плашка: `rect x=3 y=3 w=474 h=216`, радиус 16 в основном знаке, 26 в компактном
- разметка корта: боковые линии, линии подачи, центральная линия подачи, сетка по центру
- мяч: круг r=52 в основном знаке (поверх него «ФТСО»), r=62 в компактном (поверх него две дуги-полоски)
- круговая надпись только в основном знаке, по дугам r=76 (верх) и r=78 (низ)

## Цвета

| Токен | Hex | Назначение |
|---|---|---|
| `--logo-plate` | `#0d5236` | плашка корта, буквы на мяче, полоски мяча |
| `--logo-line` | `#2ecf8f` | разметка корта, кольцо |
| `--logo-ball` | `#f4f7f4` | мяч |
| фон тёмной темы | `#16232b` | подложка для эффекта свечения |

Одна палитра в обеих темах. Инверсий, перекрашивания линий и подмены мяча на жёлтый — нет.

## Эффект

Знак всегда идёт с ореолом, меняется только его цвет по теме. Реализовать как CSS-фильтр на элементе с логотипом, не запекать в SVG:

```css
.logo-seal              { filter: drop-shadow(0 0 18px rgba(13, 82, 54, .55)); }  /* светлая тема */
:root[data-theme="dark"] .logo-seal { filter: drop-shadow(0 0 16px rgba(46, 207, 143, .45)); }
```

На компактном знаке в шапке ореол не нужен.

## Шапка сайта

Заменить текущий лок-ап на: `ftso-mark.svg` высотой 37 px (ширина 80 px) + подпись строкой справа, зазор 6 px.

```html
<a class="site-logo" href="/">
  <!-- инлайн содержимое ftso-mark-animated.svg, width="80" height="37" -->
  <span class="site-logo__text">
    <b>ФТСО</b>
    <small>Федерация тенниса<br>Смоленской области</small>
  </span>
</a>
```

- `b` — 11.5 px, 700, letter-spacing .06em; светлая тема `#0d5236`, тёмная `#ffffff`
- `small` — 6.5 px, 400, line-height 1.25, `white-space: nowrap`; светлая `#4f6b60`, тёмная `#b9c9c2`
- вся группа по вертикали центрируется в полосе шапки, слева отступ как сейчас
- до первого пункта навигации («Главная») оставить не меньше 35 px
- на мобильной ширине подпись скрывается, остаётся только знак

Круговую надпись в шапку не ставить ни при каком размере: на 37 px она нечитаема.

## Анимация компактного знака

Мяч идёт от задней линии до задней линии и одновременно вращается — полоски выдают вращение.

Анимируется группа мяча ВНУТРИ svg, поэтому знак нужно **инлайнить в разметку**: во внешнем SVG, подключённом через `<img>`, CSS страницы не работает. Для анимированных мест использовать `ftso-mark-animated.svg` (в нём стиль встроен внутрь файла) либо вставить содержимое `ftso-mark.svg` в шаблон, заменив статический мяч на:

```html
<g class="ftso-ball">
  <circle cx="0" cy="0" r="62" fill="#f4f7f4"/>
  <path d="M-44 -44 A 70 70 0 0 1 -44 44" fill="none" stroke="#0d5236" stroke-width="7" stroke-linecap="round"/>
  <path d="M44 -44 A 70 70 0 0 0 44 44" fill="none" stroke="#0d5236" stroke-width="7" stroke-linecap="round"/>
</g>
```

```css
@keyframes ftsoBallFly {
  0%   { transform: translate(92px, 111px) rotate(0deg); }
  100% { transform: translate(388px, 111px) rotate(480deg); }
}
.ftso-ball { animation: ftsoBallFly 5.2s cubic-bezier(.4, .05, .6, .95) infinite alternate; }

@media (prefers-reduced-motion: reduce) {
  .ftso-ball { animation: none; transform: translate(240px, 111px); }
}
```

Координаты — в единицах viewBox `0 0 480 222`, центр мяча в нуле группы, поэтому вращение идёт вокруг своего центра.

Правила запуска:

- в шапке сайта — один прогон при загрузке страницы и повтор по наведению на логотип; бесконечный цикл в шапке не ставить
- бесконечный цикл допустим только на крупных декоративных вставках: заглушки, экран загрузки, пустые состояния календаря
- при `prefers-reduced-motion: reduce` мяч стоит в центре корта
- в печати, OG-картинке и favicon — только статичный знак

## Правила

- минимальная ширина компактного знака — 52 px; ниже только `ftso-favicon.svg`
- свободное поле вокруг знака — не меньше высоты мяча
- не растягивать по одной оси, не менять радиусы, не добавлять обводок и градиентов
- не ставить знак на фото и на цветные фоны без плашки: только на #16232b, #ced8d4, белый или #e2e9ee
- alt для основного знака — «Федерация тенниса Смоленской области», для компактного — «ФТСО»

## Приёмка

1. Шапка в светлой и тёмной теме: знак 37 px, подпись в две строки, зазор до навигации ≥ 35 px, ничего не наезжает.
2. Favicon виден в табе и в закладках, узнаётся мяч.
3. OG-картинка: знак по центру, поля соблюдены, при пересылке ссылки не обрезается.
4. Футер и «О Федерации»: основной знак, круговая надпись читается.
5. Zoom 200% и мобильная ширина 360 px — знак не деформируется.
6. Анимация: один прогон при загрузке, повтор по наведению, мяч не выходит за плашку, при reduce-motion стоит в центре.
