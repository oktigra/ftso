## Шесть дефектов, найденных на живых данных
1. Микст писался как `double`; UNIQUE (турнир, игрок, дисциплина) + INSERT OR REPLACE тихо
   затирал одно из двух парных мест. Введена дисциплина `mixed` с миграцией. PR #174.
2. Незакрытый `</form>` на Сводке — кнопка пересчёта рейтинга работала на форму плашки. PR #175.
3. Микст подписывался «одиночный» в таблице итоговых мест; внешняя сверка из-за этого
   двоила результаты. PR #176.
4. Пол в миксте схлопывался в мужской (раздел «пол: X»). Теперь по окончанию фамилии
   с предупреждением, когда правило не срабатывает. PR #178.
5. Дубль игрока: «Фамилия Имя» не связывался с заведённым «Фамилия Имя Отчество». PR #178.
6. Обязательное имя запирало карточки из импорта: 20 записей ветеранов нельзя было править
   вовсе. При правке имя больше не обязательно, при создании — обязательно. PR #179.

Пять из шести нашёл браузерный агент на живом сайте, шестой вылез из сверки рейтинга.
