## Слепые места и грабли сессии
- `OPEN.mjs --accept` после повторных прогонов в одной песочнице отдаёт «НЕ ЗАМЕРЕНО [429]»;
  эталон приёмки — прямой `node acceptance.mjs` (WORK у него временный, mkdtemp).
- `cp .env.example .env` даёт ложный провал «секретов в git нет»: плейсхолдер совпадает сам с
  собой в отслеживаемом примере. В `.env` вписывать случайные секреты.
- В acceptance против живого `inst` — только асинхронный `spawn`: `spawnSync` замораживает event
  loop того же процесса, и curl не дожидается ответа.
- `git init --bare` без `-b main` → клон без HEAD в тестах; `pkill -f` по тексту своей команды
  убивает свою же оболочку.
- systemd зовёт копии из `/root`, а не файлы репо: до PR #20 задача 1 была смёржена, но не
  активна на бою. Теперь копии самообновляются (`sync_copy`).
